Primeira instalação neste aparelho

Se não existe uma versão anterior instalada, baixe o APK de testes. O Android poderá pedir autorização para instalar pelo navegador.

Baixar APK Android

Após esta instalação, as versões web compatíveis serão baixadas em segundo plano e ativadas ao fechar completamente e reabrir o app. Uma rota em andamento não será recarregada.

Já tenho a versão anterior instalada

Não desinstale o aplicativo antes de preservar os dados. O APK antigo tem outra assinatura de testes e o Android impede a atualização por cima dele. O histórico e alguns planejamentos ficam apenas no aparelho.

O caminho validado utiliza um computador para preservar o APK anterior e todo o armazenamento local, verificar o backup, instalar o novo e restaurar os dados. Sem computador, mantenha o aplicativo anterior e use a versão web por enquanto.

Tenho computador e quero fazer a migração completa

Você precisa de Python 3.11 ou superior, Android Platform Tools oficial, cabo USB e autorização de depuração USB no tablet. Encerre a rota e salve as alterações antes de começar.

  1. Baixe o APK acima e a ferramenta abaixo para uma pasta particular no computador.
  2. Conecte apenas o tablet correspondente e confirme a autorização USB nele.
  3. Abra o terminal nessa pasta. Faça primeiro somente o backup:
    python traxelo-migrar.py
  4. Para fazer a troca após a conferência:
    python traxelo-migrar.py --apk traxio-android-testes.apk --migrate
    A ferramenta cria e verifica outro backup. Só substitui o aplicativo depois que você digitar MIGRAR.
  5. Confira clientes, localizações, histórico e login após a restauração. Guarde o backup e desative a depuração USB quando terminar.
Baixar ferramenta de migração

O backup contém informações privadas e pode conter a sessão de acesso. Guarde-o com segurança; não o envie pelo chat. A ferramenta foi validada em emulador com dados sintéticos. Nenhuma alteração foi realizada no seu tablet.

Novas permissões e componentes Android ainda exigirão outro APK. A migração Google Maps continua aguardando a regularização do faturamento.
