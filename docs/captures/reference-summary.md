# Comparação com o kit visual aprovado

As mesmas referências PNG e proporções foram usadas nas duas execuções. Uma variação negativa indica redução da diferença média RGB (escala de 0 a 255). Estes valores não representam porcentagens de fidelidade. Dados de conta, fontes renderizadas pelo navegador e cartografia real também influenciam a medida.

| Tela | Antes do kit | Depois do kit | Variação |
| --- | ---: | ---: | ---: |
| login | 12.99 | 15.77 | 2.78 |
| painel | 20.63 | 24.74 | 4.11 |
| clientes | 18.99 | 19.13 | 0.14 |
| mapa | 33.10 | 33.53 | 0.42 |
| dados | 18.78 | 19.40 | 0.62 |

Os textos dos banners da versão nova são HTML acessível; o lettering da marca e os recursos gráficos aprovados continuam sendo exibidos a partir dos recortes originais. O histórico e variantes móveis não têm referência específica no kit.
